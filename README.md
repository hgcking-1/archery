# 3학년 양궁 기록장

서울사대부설여중 3학년 양궁 수업용 점수 기록 사이트입니다. **서버·Firebase 없이 구글 크롬만으로** 동작합니다.

- 학생: 학번 + 비밀번호(4자리)로 로그인 → 과녁판을 눌러 한 발씩 기록(하루 최대 30발)
- 날짜별 한 발 평균 그래프, 우리 반 순위(이름), 전체 TOP 20(반만 표시)
- 선생님: 선생님 비밀번호로 로그인 → 날짜별 기록·고치기, 반별 평균, 명단·비밀번호 관리, CSV 내려받기, 백업·합치기

## 사용 방법

1. 크롬에서 사이트를 엽니다. (GitHub Pages 주소 또는 `index.html` 파일을 크롬으로 직접 열기)
2. **[선생님 로그인]** 에서 처음 한 번 선생님 비밀번호를 정합니다.
3. `명단·비밀번호` 탭에 엑셀 명단(반·번호·학번·이름·비밀번호)을 붙여넣고 [명단 저장]을 누릅니다.
4. 학생은 학번과 비밀번호로 들어가 기록합니다.

## 꼭 알아 두기

- **기록은 이 컴퓨터의 크롬에만 저장됩니다.** (크롬의 localStorage) 다른 컴퓨터·다른 브라우저·시크릿 창에서는 보이지 않습니다.
  학생들이 **같은 컴퓨터의 같은 크롬**을 써야 순위와 선생님 화면에 모두의 기록이 모입니다.
- 크롬의 "사이트 데이터/쿠키 삭제"를 하면 기록이 사라집니다. `백업` 탭에서 수업이 끝날 때마다 파일(.json)로 받아 두세요.
- 다른 컴퓨터의 기록을 한곳에 모을 때도 `백업` 탭의 [불러와 합치기]를 씁니다.
- 로그인 상태는 탭을 닫으면 풀립니다.
- 서버가 없어서 보안은 **간단한 수준**입니다. 크롬 개발자 도구를 아는 학생은 저장된 자료를 볼 수 있습니다.
  선생님 비밀번호는 암호화해 저장하지만, 학생 비밀번호는 명단과 함께 그대로 저장됩니다. 중요한 정보는 넣지 마세요.
- 선생님 비밀번호를 잊으면 크롬의 사이트 데이터를 지워야 하고, 기록도 함께 사라집니다. (백업 파일로 되살릴 수 있어요)

학생 비밀번호 목록(엑셀, `students.json`)은 이 저장소에 넣지 않습니다. (`.gitignore`)
