# 3학년 양궁 기록장

서울사대부설여중 3학년 양궁 수업용 점수 기록 사이트입니다.

- 학생: 학번 + 비밀번호(4자리)로 로그인 → 과녁판을 눌러 한 발씩 기록(하루 최대 30발)
- 날짜별 한 발 평균 그래프, 우리 반 순위(이름), 전체 TOP 20(반만 표시)
- 선생님: 구글 로그인 → 날짜별 기록·고치기, 반별 평균, 명단·비밀번호 관리, CSV 내려받기
- 저장소: Firebase (프로젝트 archery-snug), 보안 규칙은 `firestore.rules`

※ 학생 비밀번호 목록은 이 저장소에 넣지 않습니다.

## 배포 전에 꼭 바꾸기

개인정보 보호를 위해 선생님 구글 이메일은 자리표시자(`teacher1@example.com`, `teacher2@example.com`)로 바꿔 두었습니다.
배포 전에 아래 두 곳을 **같은 실제 이메일**로 바꿔 주세요. 안 바꾸면 선생님 화면과 관리 권한이 열리지 않습니다.

- `firestore.rules` 의 `isTeacher()` 안 이메일 목록
- `public/index.html` 의 `TEACHERS` 배열
