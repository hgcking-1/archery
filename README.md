# 3학년 양궁 기록장

서울사대부설여중 3학년 양궁 수업용 점수 기록 사이트입니다. 구글 크롬에서 열고, Firebase는 쓰지 않습니다.

- 학생: 학번 + 비밀번호(4자리)로 로그인 → 과녁판을 눌러 한 발씩 기록(하루 최대 30발)
- 날짜별 한 발 평균 그래프, 우리 반 순위(이름), 전체 TOP 20(반만 표시)
- 선생님: 선생님 비밀번호로 로그인 → 날짜별 기록·고치기, 반별 평균, 명단·비밀번호 관리, CSV 내려받기, 백업·합치기

## 저장 방식 두 가지

| | 서버 주소 비움 (지금 기본값) | **구글 시트 연결 (여러 기기용)** |
|---|---|---|
| 기록 저장 위치 | 접속한 컴퓨터의 크롬 | 선생님 구글 시트 |
| 학생이 각자 기기로 접속 | 기록이 기기마다 따로 쌓임 ✗ | 한곳에 모임 ✓ |
| 순위·선생님 화면 | 그 기기의 기록만 | 모든 학생 기록 |
| 설정 | 없음 | 아래 5분 설정 |

**학생들이 각자 기기로 들어오면 "구글 시트 연결"이 필요합니다.**

## 여러 기기에서 함께 쓰기 (구글 시트 연결, 한 번만 설정)

모두 크롬에서 선생님 구글 계정으로 합니다.

1. 새 구글 시트를 만듭니다. 주소창에 `sheets.new` 입력 → 이름을 `양궁기록`으로.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 **전부 복사해 붙여넣습니다.**
   맨 위의 `TEACHER_PASSWORD = "CHANGE-ME"` 를 **선생님 비밀번호로 바꾸고** 저장(💾)합니다.
   (이 코드는 선생님 구글 계정에서만 보이므로 비밀번호가 새지 않습니다. 이 저장소에는 올리지 마세요.)
4. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 검토/허용 → 나오는 **웹 앱 URL(`…/exec`로 끝남)** 을 복사합니다.
5. 이 저장소의 [`config.js`](config.js)를 열어(GitHub에서 연필 ✏ 버튼) 따옴표 안에 URL을 붙여넣고 **Commit** 합니다.
   1~2분 뒤 사이트가 서버 모드로 바뀝니다. (로그인 화면에 "기록은 선생님의 구글 시트에 저장돼요"가 보이면 성공)
6. 사이트에서 **[선생님 로그인]** → 3번에서 정한 비밀번호 → `명단·비밀번호` 탭에 명단을 붙여넣습니다.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**를 해야 반영됩니다. (주소는 그대로)

### 서버 모드에서 알아 둘 것

- 점수 합계·평균은 서버가 다시 계산하고, 학생은 **오늘 날짜** 기록만 저장할 수 있습니다. 다른 학생의 기록은 바꿀 수 없습니다.
- 학번당 비밀번호를 5번 틀리면 10분간 잠깁니다. 선생님 비밀번호도 같습니다.
- 시트의 `students`(명단·비밀번호) / `sessions`(기록) / `pub`(이름 없는 기록) 탭을 직접 열어 볼 수 있습니다. **시트를 다른 사람과 공유하지 마세요.** (비밀번호가 들어 있어요)
- 로그인은 12시간 유지됩니다. 선생님 비밀번호를 바꾸려면 `Code.gs`를 고치고 새 버전으로 배포하세요.
- 구글 한도: 한 번에 많은 학생이 동시에 누르면 느려지거나 실패할 수 있어, 사이트가 자동으로 3번까지 다시 시도합니다. 한 반(30명 안팎) 수업이면 괜찮을 것으로 예상하지만 **실제 구글 서버에서 여러 명이 동시에 쓰는 시험은 아직 못 해 봤으니, 수업 전에 몇 명이 함께 한 번 써 보세요.**
- 학교 구글 계정이 "모든 사용자" 배포를 막아 놓았다면 4번에서 그 옵션이 보이지 않습니다. 그때는 개인 구글 계정으로 만들어야 합니다.
- 서버 주소(URL)를 아는 사람은 로그인 요청을 보낼 수 있지만, 학번+비밀번호 없이는 아무 자료도 볼 수 없습니다.

## 서버 없이 쓸 때 (config.js의 주소가 비어 있을 때)

- 기록은 **그 컴퓨터의 크롬에만** 저장됩니다. (크롬의 localStorage) 다른 컴퓨터·브라우저·시크릿 창에서는 보이지 않습니다.
  한 대의 컴퓨터를 학생들이 함께 쓰는 경우에만 적합합니다.
- 처음 [선생님 로그인]에서 선생님 비밀번호를 정합니다. 잊으면 크롬의 사이트 데이터를 지워야 해서 기록도 사라집니다.
- 크롬의 "사이트 데이터/쿠키 삭제"를 하면 기록이 사라지니 `백업` 탭에서 파일(.json)로 받아 두세요.
- 서버가 없어서 보안은 간단한 수준입니다. 크롬 개발자 도구를 아는 학생은 저장된 자료를 볼 수 있습니다.

로그인 상태는 탭을 닫으면 풀립니다. 학생 비밀번호 목록(엑셀, `students.json`)은 이 저장소에 넣지 않습니다. (`.gitignore`)
